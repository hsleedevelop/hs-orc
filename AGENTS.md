# hs-orc agent agreement — external TT board only

When editing the external Obsidian `Projects/hs-orc.md` board, read its latest full contents and preserve all five level-two lane headings, including empty lanes. Preserve existing `tt:v1` IDs, `managed` lists, Source pointers, child checkboxes and notes; identify enrolled cards by ID, not title or position. Recheck board and selected-card hashes before writing. If a rename, move, source retirement or deletion is ambiguous or the preview became stale, leave that change for review instead of silently deleting metadata or rebuilding an old card.

This narrow instruction does not authorize a board write, a new project task, TT configuration/registry/cron/Skill changes, or Discord delivery. It does not prescribe changes to unrelated hs-orc code and documentation.
